# 🏘️ 복지마을 타이쿤 (Welfare Village Tycoon)

인구 500명의 작은 마을에 사회복지 예산 **50억 원**이 내려왔습니다.
주민의 절반은 독거노인·발달장애인·위기청소년·기초생활수급자·다문화이주민·북한이탈주민입니다.

땅을 사서 마을을 넓히고, 길을 내고, 복지시설을 세우고, 프로그램을 직접 기획하고,
사례관리로 이웃 한 명 한 명을 도우며 **"복지가 좋아 사람들이 모여드는 마을"** 을
만드는 3D 웹 시뮬레이션 게임입니다.

빌드 도구도, 서버도, 계정도 필요 없는 **순수 정적 웹앱**입니다.

## 실행

```bash
# 아무 정적 서버나 사용하면 됩니다
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages로 배포하려면 Settings → Pages에서 브랜치를 `main`, 폴더를 `/ (root)`로
지정하면 됩니다. 루트에 `index.html`이 있어 그대로 서빙됩니다.

### 건물 디자인 커스터마이징

공원을 뺀 모든 시설은 **건물 선택 → 디자인 선택 → 색상 선택 → 위치 선택** 순서로 짓습니다.

- 디자인 5종: 모던형 · 친환경형(옥상 녹화) · 공공기관형(깃대·기둥) · 도시형(고층) · 따뜻한 복지시설형(박공지붕·나무 차양) — 저마다 형태가 실제로 다르게 생겼습니다.
- 외벽 색 7종 · 지붕 색 6종 중 자유롭게 조합.
- 같은 시설을 여러 채 지어도 채마다 디자인·색을 다르게 골라 나만의 마을을 만들 수 있습니다.
- 배치 단계에서 고른 디자인·색 그대로 반투명 미리보기가 뜨고, 클릭하면 그 모습 그대로 지어집니다.
- 건물마다 저장되는 정보라 새로고침·재접속해도 그대로 유지됩니다.

### 주거 수용량과 도시등급

인구는 무한정 늘지 않습니다. **주거 수용 인구**(원래 살던 민가 + 지은 공공아파트가 감당할 수 있는
인구)를 넘어서기 시작하면 새로 이사 오는 사람이 줄어듭니다.

- 수용률이 **80%**를 넘으면 "주거공간 확충이 필요합니다" 안내가 한 번 뜹니다 (여유가 다시 생기면 재무장).
- 수용률이 **95%**를 넘으면 전입 인원이 4분의 1 수준으로 크게 줄어듭니다.
- HUD 왼쪽 위와 통계 패널에서 `현재 인구 / 최대 수용 인구`를 항상 확인할 수 있습니다.

**도시등급**은 인구를 기준으로 한 5단계 성장 지표입니다 (Lv.1 작은 마을 → Lv.5 복지 광역도시).
일부 시설(빌딩형·대단지 공공아파트 등)은 인구·도시등급 조건을 채워야 건설 메뉴에서 잠금이 풀립니다.
잠긴 시설은 🔒 표시와 함께 해금 조건, 진행률 막대가 같이 보입니다.

### 복지 접근성과 복지사각지대

지도를 4×4칸짜리 구역(파셀) 단위로 나눠 구역마다 "누가 얼마나 가까이에서 서비스를 받을 수 있는가"를
계산합니다. 인구는 그 구역의 **주거 수용량 비중**만큼 산다고 봅니다 — 민가·아파트가 많은 구역일수록
실제로 사람이 많이 사는 구역으로 취급됩니다.

- 구역 접근성 점수(0~100점) = 반경 11칸 안에 있는 **프로그램 운영 가능 시설**(host 시설)들의
  거리 가중 합. 가까이 여러 시설이 있을수록 점수가 높습니다.
- 70점 이상은 넉넉한 구역, 40점 미만이면서 사람이 사는 구역은 **복지사각지대**로 판정합니다.
- 사각지대가 있으면서 동시에 아주 잘 커버된 구역도 있으면 "시설이 한쪽에 몰려 있다"는 안내가 뜹니다
  (해소되면 재무장해서 다음에 또 몰리면 다시 알려줍니다).
- 마을 전체 접근성 점수(인구 가중 평균)가 높으면 매달 만족도가 조금씩 오르고, 낮으면 조금씩 깎입니다.
- 통계 패널 → 🗺️ 복지 접근성에서 "지도에 히트맵 표시"를 누르면 3D 지도 위에 구역별 점수가
  초록·주황·빨강으로 바로 보입니다. 사각지대 구역 목록도 함께 볼 수 있습니다.

일곱 집단이 살고, 시작 시점에 절반이 취약계층입니다. 집단마다 관심 있는 프로그램 키워드와

### 공모사업 심사 기준

신청서는 100점 만점으로 채점되고 **70점 이상이면 선정**됩니다. 떨어져도 2개월 뒤 다시 도전할 수 있고,
항목별로 무엇이 부족했는지 알려줍니다.

| 항목 | 배점 | 보는 것 |
| --- | --- | --- |
| 대상과 사업 취지가 드러나는가 | 25 | 공모별 핵심어가 신청서에 담겼는지 |
| 목적이 구체적으로 서술되었는가 | 20 | 30자 이상 |
| 목표가 숫자로 측정 가능한가 | 25 | 정량 목표(인원·횟수·지표) |
| 프로그램 내용이 구체적인가 | 20 | 60자 이상 |
| 사업을 수행할 시설이 있는가 | 10 | 관련 시설 보유 여부 |

### 보건복지부 포상

신청서를 쓰는 공모사업과 달리, 아래 두 상은 마을이 일정 기간 계속 좋은 상태를 유지하면
보건복지부가 매달 자동으로 심사해 수여합니다. 조건에 못 미치는 달이 하루라도 끼면 그 상은
처음부터 다시 세야 하고, 여러 번 받을 수 있습니다.

| 상 | 조건 | 포상금 | 점수 보너스 |
| --- | --- | --- | --- |
| 🎖️ 복지마을 선도우수사례 표창장 | 평균 만족도 72점 이상을 6개월 연속 유지 | 5억 원 | +800점 |
| 🏅 우수 사회복지 프로그램 보건복지부 장관상 | 프로그램 평균 평점 4.0점 이상 + 취약계층 평균 만족도 68점 이상을 6개월 연속 유지 | 7억 원 | +1,000점 |

### 점수판

오른쪽 위에 세 지표와 총점이 뜹니다.

```
총점 = 인구 + 만족도×20 + 종결사례×100 + 수상 점수 보너스
```

평판과 시설 수는 점수에 직접 들어가지 않습니다. 대신 평판이 높아야 사람이 이사 오고(→인구),
시설이 있어야 만족도가 오르니(→만족도) 결국 점수로 돌아옵니다. 보건복지부 포상만 예외로
점수에 곧바로 더해집니다.

### 도시계획 규칙

지도는 28×28칸을 4칸짜리 구역 49개로 나눈 것이고, 시작할 때는 가운데 9개 구역만 우리 마을입니다.

- 시설은 **우리 땅 위** + **도로에 접한 자리**에만 지을 수 있습니다. 길이 없으면 먼저 도로를 내야 합니다.
- 새로 지은 시설은 **자동으로 도로 쪽을 바라보도록** 회전합니다. 여러 방향에 도로가 접해 있으면 가장 많이 접한 쪽을 향합니다.
- **원래 살던 주민의 집은 절대 철거되지 않습니다.** 건물도 도로도 집이 있는 자리는 피해서, 다른 빈 땅을 찾아 지어야 합니다. 대신 집을 클릭해 우리 땅 안의 다른 빈 자리로 **이사**를 보낼 수는 있습니다.
- 나무·화단 위에는 별도로 철거하지 않아도 바로 건물을 지을 수 있습니다 (건설 시 자동으로 정리됨).
- 플레이어가 놓은 꾸미기 요소도 같은 이유로 보호됩니다 — 실수로 뭔가를 지으며 없어지지 않고, 직접 철거해야만 사라집니다.
- 도로를 놓으면 **직선 구간 양옆에 가로수가 자동으로 심겨** 가로수길이 만들어집니다. 도로를 걷어낼 때 그 길에만 의지하던 시설이 있으면 막습니다 (다른 길을 먼저 내야 함).
- 매입 가능한 구역은 지도에서 노란 테두리로 표시되고, 가격표는 부지 매입 모드에서만 뜹니다.

### 🎪 미션 — 다 함께 어울리는 마을

**주민커뮤니티센터**를 처음 지으면 미션이 시작됩니다: 모든 주민이 함께 어울릴 수 있는 프로그램을
기획해 달라는 미션입니다. 주민커뮤니티센터에서, **전체 주민**을 대상으로, 제목이나 설명에
"공동체·이웃·마을·축제·나눔" 같은 말이 담긴 프로그램을 개설하면 미션이 완료되고 특별교부금
3억 원과 평판 보너스가 지급됩니다. 이 센터는 마을 행사·축제를 여는 사랑방이자, 어르신이 살던
곳에서 계속 지낼 수 있도록(AIP · Aging In Place) 이웃이 함께 살피는 **공동케어회의**의 무대이기도
합니다.

**통합돌봄센터**는 의료·장기요양·돌봄을 한 곳에서 잇는 시설로, 맞춤형 케어플랜을 통해 어르신과
장애인의 삶을 지원합니다.

### 그 외

- 평판이 오르면 **다른 지역에서 주민이 이주**해 와 인구가 늘고, 분기마다 인구 비례 교부금이 들어옵니다.
- **사례를 종결할 때마다** 주민 행복지수가 올라 보조금이 추가로 들어옵니다. 만족도가 높을수록 큰 금액이 돌아옵니다.
- 꾸미기 요소를 많이 놓을수록 마을 미관이 좋아져 만족도가 아주 조금씩 오릅니다 (상한 있음).
- 🎯 목표: **인구 1,000명 · 평균 만족도 80점** 달성
- 조작: 좌드래그 회전 · 우드래그 이동 · 휠 줌 · `Space` 다음 달 · `ESC` 취소
- 진행 상황은 브라우저(localStorage)에 매달 자동 저장됩니다. 지형은 저장된 시드로 재현되므로
  다시 접속해도 같은 마을이 나옵니다.

## 랭킹 설정 (Supabase)

랭킹은 **유일하게 서버가 필요한 기능**입니다. 마을 세이브는 여전히 브라우저에만 있고,
서버로 나가는 것은 이름·소속기관·마을이름·총점·인구·만족도·종결사례·경과개월뿐입니다.
이름·소속기관·마을 이름은 순위표에서 다른 참가자에게 그대로 보입니다. 소속기관은 비워둘 수 있습니다.

1. Supabase 대시보드 → **SQL Editor** 를 열고 [`supabase/schema.sql`](supabase/schema.sql)을
   통째로 붙여넣어 실행합니다. 여러 번 실행해도 안전합니다 (이미 테이블이 있어도 소속기관 칸만 추가됨).
2. 끝입니다. `leaderboard.js` 상단에 프로젝트 URL과 anon 키가 이미 들어 있습니다.

다른 Supabase 프로젝트로 바꾸려면 `leaderboard.js`의 `CONFIG`를 고치거나,
런타임에 `Leaderboard.configure({ url, key })`를 호출하면 됩니다.

### 키와 권한에 대해

`leaderboard.js`에 들어 있는 것은 **anon public 키**입니다. 브라우저에 노출되는 것을
전제로 설계된 공개 키라 저장소에 있어도 괜찮습니다. 실제 보호는 테이블의 RLS 정책이 합니다.

| 동작 | 허용 | 방식 |
| --- | --- | --- |
| 순위표 조회 | ✅ | `select` 정책 |
| 내 기록 등록 | ✅ | `insert` 정책 |
| 남의 기록 수정 | ❌ | `update` 정책을 만들지 않음 |
| 남의 기록 삭제 | ❌ | `delete` 정책을 만들지 않음 |

RLS가 켜진 테이블은 정책이 없는 동작을 전부 거부합니다.
**`service_role` 키는 절대 게임 코드에 넣지 마세요.** 그 키는 RLS를 통째로 우회합니다.

기록을 지워야 할 일이 생기면 Supabase 대시보드의 Table Editor에서 직접 하시면 됩니다.

## 구조

프레임워크 없는 순수 JavaScript 6개 모듈입니다.

| 파일 | 역할 |
| --- | --- |
| `data.js` | 지도·토지·도로 상수, 시설 10종, 프로그램 키워드, 사례 욕구·지역자원, 이벤트, 이름 풀 |
| `sim.js` | 시뮬레이션 엔진 — 예산·인구·만족도·평판, 토지/도로 규칙, 프로그램 운영, 사례관리, 월 진행, 저장 |
| `world.js` | 3D 월드 (three.js) — 시드 기반 지형, 구역 소유 표시, 도로 렌더링, 시설 메시, 주민 |
| `leaderboard.js` | 랭킹 클라이언트 (Supabase REST) — 이 파일만 서버와 통신합니다 |
| `ui.js` | HUD·패널·모달·차트·사운드 |
| `main.js` | 부트스트랩과 렌더 루프, 모드 제어 |

`sim.js`는 three.js를 전혀 모르고, `world.js`는 UI를 모릅니다.
게임 규칙만 바꾸고 싶다면 `data.js`와 `sim.js`만 보면 됩니다.
