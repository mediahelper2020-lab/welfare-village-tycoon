# 🏘️ 복지마을 타이쿤 (Welfare Village Tycoon)

인구 500명의 작은 마을에 사회복지 예산 **50억 원**이 내려왔습니다.
주민의 절반은 독거노인·발달장애인·기초생활수급자입니다.

땅을 사서 마을을 넓히고, 길을 내고, 복지시설을 세우고, 프로그램을 직접 기획하고,
사례관리로 이웃 한 명 한 명을 도우며 **"복지가 좋아 사람들이 모여드는 마을"** 을
만드는 3D 웹 시뮬레이션 게임입니다.

빌드 도구도, 서버도, 계정도 필요 없는 **순수 정적 웹앱**입니다.

## 실행

```bash
# 아무 정적 서버나 사용하면 됩니다
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages로 배포하려면 Settings → Pages에서 브랜치를 `main`, 폴더를 `/ (root)`로
지정하면 됩니다. 루트에 `index.html`이 있어 그대로 서빙됩니다.

## 놀이 방법

| 메뉴 | 내용 |
| --- | --- |
| 🗺️ **부지 매입** | 마을과 맞닿은 구역(4×4칸)을 사들여 영토를 넓힘. 넓힐수록 다음 구역 값이 오름 (2억 → +8,000만씩) |
| 🛣️ **도로 건설** | 우리 땅 위를 **드래그해서** 길을 놓음 (칸당 500만 원). 연석·중앙선·횡단보도가 이웃에 맞춰 자동으로 그려짐 |
| 🏗️ **건설** | 종합사회복지관·가족센터·경로당·무료급식소 등 10종의 복지시설을 예산 안에서 건축 (철거·환급 가능) |
| 📋 **프로그램** | 제목과 세부 설명을 **직접 작성**해 프로그램 개설. 글에 담긴 키워드(건강·요리·나들이·스마트폰·일자리…)에 따라 대상별 호응이 달라지고, 매달 참여 인원·평점·참여자 후기가 돌아옴 |
| 🤝 **사례관리** | 당사자 한 명 한 명의 사연과 취약점(욕구)을 읽고, 17종의 **지역자원**(보건지소 방문간호, LH 주거복지센터, 푸드뱅크, 법률구조공단…) 중 맞는 것을 연계해 사례를 종결 |
| 📊 **통계** | 인구·만족도 추이 차트, 대상별 만족도, 인구 구성, 예산 집행 현황 (표 보기 지원) |

### 도시계획 규칙

지도는 28×28칸을 4칸짜리 구역 49개로 나눈 것이고, 시작할 때는 가운데 9개 구역만 우리 마을입니다.

- 시설은 **우리 땅 위** + **도로에 접한 자리**에만 지을 수 있습니다. 길이 없으면 먼저 도로를 내야 합니다.
- 도로를 걷어낼 때 그 길에만 의지하던 시설이 있으면 막습니다 (다른 길을 먼저 내야 함).
- 매입 가능한 구역은 지도에서 노란 테두리로 표시되고, 가격표는 부지 매입 모드에서만 뜹니다.

### 그 외

- 평판이 오르면 **다른 지역에서 주민이 이주**해 와 인구가 늘고, 분기마다 인구 비례 교부금이 들어옵니다.
- 🎯 목표: **인구 1,000명 · 평균 만족도 80점** 달성
- 조작: 좌드래그 회전 · 우드래그 이동 · 휠 줌 · `Space` 다음 달 · `ESC` 취소
- 진행 상황은 브라우저(localStorage)에 매달 자동 저장됩니다. 지형은 저장된 시드로 재현되므로
  다시 접속해도 같은 마을이 나옵니다.

## 구조

프레임워크 없는 순수 JavaScript 5개 모듈입니다.

| 파일 | 역할 |
| --- | --- |
| `data.js` | 지도·토지·도로 상수, 시설 10종, 프로그램 키워드, 사례 욕구·지역자원, 이벤트, 이름 풀 |
| `sim.js` | 시뮬레이션 엔진 — 예산·인구·만족도·평판, 토지/도로 규칙, 프로그램 운영, 사례관리, 월 진행, 저장 |
| `world.js` | 3D 월드 (three.js) — 시드 기반 지형, 구역 소유 표시, 도로 렌더링, 시설 메시, 주민 |
| `ui.js` | HUD·패널·모달·차트·사운드 |
| `main.js` | 부트스트랩과 렌더 루프, 모드 제어 |

`sim.js`는 three.js를 전혀 모르고, `world.js`는 UI를 모릅니다.
게임 규칙만 바꾸고 싶다면 `data.js`와 `sim.js`만 보면 됩니다.

Pretendard는 변수 폰트를 유니코드 범위 13조각으로 분할해 포함했습니다.
초기 로드는 `pretendard-core.woff2` 131KB뿐이고, 플레이어가 프로그램 제목에 입력한
임의의 한글은 해당 조각만 추가로 내려받습니다.
